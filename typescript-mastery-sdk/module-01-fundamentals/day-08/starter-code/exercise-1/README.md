# Exercise 1: Create package.json from Scratch

Follow the instructions in `EXERCISES.md` to manually create a `package.json` file in this directory.

## Instructions

1. Create a file named `package.json` in this folder
2. Fill it with the required fields (see EXERCISES.md Day 08, Exercise 1)
3. Run `npm install` to validate it works

## Validation

After creating your `package.json`, run:

```bash
npm install
```

If successful, dependencies will be installed without errors!
