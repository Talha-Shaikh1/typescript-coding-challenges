# 📞 Phone Validator - Week 1 Practice Project

A TypeScript utility for validating and formatting phone numbers.

---

## 🎯 Project Goal

Apply all Week 1 TypeScript concepts to build a production-ready utility!

---

## 📂 Project Structure

```
phone-validator/
├── src/
│   ├── types.ts          # Type definitions
│   ├── errors.ts         # Custom error classes
│   ├── validator.ts      # Validation logic
│   ├── formatter.ts      # Formatting logic
│   └── index.ts          # Public API
├── examples/
│   └── usage.ts          # Usage examples
└── README.md             # This file
```

---

## 🚀 Getting Started

### Step 1: Complete the Implementation

Work through exercises in order:
1. **types.ts** - Define all types and interfaces
2. **errors.ts** - Create custom error classes
3. **validator.ts** - Implement validation functions
4. **formatter.ts** - Implement formatting functions
5. **index.ts** - Export clean public API
6. **examples/usage.ts** - Add usage examples

### Step 2: Test Your Code

```bash
# Compile TypeScript
npx tsc --noEmit

# Run examples
npx tsx examples/usage.ts
```
