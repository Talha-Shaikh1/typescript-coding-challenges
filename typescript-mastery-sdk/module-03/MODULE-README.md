## 📖 Week-by-Week Breakdown

### ⏳ Week 05: Async Patterns

**Goal:** Master asynchronous JavaScript/TypeScript

#### Topics to Cover:
- **Day 01 (29):** Promises Deep Dive
  - Promise fundamentals
  - Promise states (pending, fulfilled, rejected)
  - Promise chaining
  - Error handling with `.catch()`
  - **SDK Connection:** Async API calls foundation

- **Day 02 (30):** async/await Mastery
  - async functions
  - await keyword
  - Error handling with try/catch
  - Sequential vs parallel execution
  - **SDK Connection:** Clean async code patterns

- **Day 03 (31):** Promise Combinators
  - `Promise.all()` - Parallel execution
  - `Promise.race()` - First to complete
  - `Promise.allSettled()` - All results
  - `Promise.any()` - First success
  - **SDK Connection:** Batch API operations

- **Day 04 (32):** Error Handling in Async Code
  - Try/catch patterns
  - Error propagation
  - Custom error types
  - Error recovery strategies
  - **SDK Connection:** Robust error handling

- **Day 05 (33):** Advanced Async Patterns
  - Async generators
  - Async iterators
  - Event loop understanding
  - Microtasks vs macrotasks
  - **SDK Connection:** Streaming responses

- **Day 06 (34):** Timeouts & Cancellation
  - AbortController and AbortSignal
  - Timeout patterns
  - Cancellable operations
  - Race conditions
  - **SDK Connection:** Request cancellation

- **Day 07 (35):** Week Practice Project
  - Async utility library
  - Error handling patterns
  - Promise-based workflows
  - **SDK Connection:** Async foundation ready
